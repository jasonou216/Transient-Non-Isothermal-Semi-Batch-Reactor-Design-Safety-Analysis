# Data

| Folder | Contents | Edited by |
|---|---|---|
| `raw/` | Bench data files exactly as returned by the TA. Never modified, so the analysis can always be traced back to the original measurements. | copy in only |
| `experiments/runs.csv` | One row per fitting run: the conditions requested (T0, feed flow, feed duration, coolant T, run length) and the data file name in `raw/`. | you |
| `experiments/validation_runs.csv` | Same format, for held-out validation runs. These are never used in the fit. | you |
| `processed/` | Written by the code: `fitted_parameters.json` (read by every later step), `<run>_processed.csv` (each measurement next to the fitted model, with volume, conversion and residuals), and large intermediate grids. | the code |
| `synthetic/` | Self-test data set with the same `raw/`, `experiments/`, `processed/` layout, generated by `src/synthetic_data.py` from known parameters (`experiments/TRUE_PARAMS.json`). Not real data. | the code |

Data file columns: `time_min, CA_molL, CB_molL, CC_molL, T_K` (CSV or Excel).

| Run | File | Conditions | Purpose |
|---|---|---|---|
| R1 | `raw/G33_run_20261126_140647.csv` | T0 = Tc = 25 °C, 0.05 L/min for 20 min (1.0 L B, stoichiometric), 150 min | Baseline at low temperature: k_ref and ΔH |
| R2 | requested | T0 = Tc = 60 °C, 0.08 L/min for 12.5 min, 150 min | High temperature: E_a |
| R3 | requested | T0 = Tc = 42 °C, 0.08 L/min for 18.75 min (1.5 eq B), 150 min | Third temperature (Arrhenius check), excess B |
